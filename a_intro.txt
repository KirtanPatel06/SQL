// What is a Database?
// ==============================

// ---> Database ke baare mein sabne suna hai. Aksar jab pucha jata hai, "Database kya karta hai?", to jawab hota hai: "Database data store karta hai."

// ---> Ye statement practical sense mein sahi hai, lekin technically thoda incomplete hai.
MongoDB, PostgreSQL, MySQL jaise databases actually Database Management Systems (DBMS) hain—ye software hote hain.

// ---> Actual data physically Hard Disk ya SSD par store hota hai. DBMS us data ko organize, retrieve, update, secure, aur manage karta hai.

// ---> Isliye jab hum MongoDB ya PostgreSQL ki baat karte hain, to hum storage device ki nahi, balki us software ki baat kar rahe hote hain jo storage ko efficiently manage karta hai.


// ---------------------------------------------------------------------------------------------------
// ---> Agar DBMS na ho, to hume data ko Disk par store, update ya retrieve karne ke liye
// low-level storage logic khud implement karna padega, jo bahut complex hai.

// ---> Disk billions of blocks/pages se bani hoti hai. Inhe efficiently manage karna,
// indexing, searching, caching aur consistency maintain karna manually karna possible nahi hai.

// ---> Isliye DBMS (MongoDB, PostgreSQL, MySQL, etc.) use kiya jata hai.
// Hum sirf High-Level Queries (SQL ya DB API) likhte hain.

// ---> DBMS query ko internally optimize karke ek "Query Execution Plan" banata hai,
// phir data ko Disk se efficiently read/write karke application ko result return karta hai.

// ---> DBMS ka primary kaam storage ko manage karna aur efficient Input/Output (I/O)
// operations perform karna hota hai.

// ---> Ye sab general-purpose programming languages se bhi kiya ja sakta hai,
// lekin DBMS ye saari complexities ko handle karne ke liye specially design kiya gaya hai.
